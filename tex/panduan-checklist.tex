\section{Pre-Submission Checklist}

\textbf{Format}

\begin{itemize}
    \item A4 white paper, printed one side, correct margins (left 35 mm; top, right, bottom 25 mm).
    \item Times New Roman 12 pt everywhere; table entries may be 11 pt or smaller but legible.
    \item 1.5 line spacing for body text; single spacing for abstract, acknowledgements, long quotes, and references.
    \item First line of every paragraph indented 12.7 mm.
    \item Page numbers centred at the bottom: roman for preliminaries, arabic for text.
    \item Table captions above tables; figure captions below figures; both numbered by chapter.
    \item Tables have only three horizontal lines and no vertical lines.
    \item Equations centred and numbered by chapter.
    \item Headings follow the levels in Table \ref{tab:headings}.
    \item References follow APA 6th and are listed once at the end.
\end{itemize}

\textbf{Content}

\begin{itemize}
    \item Chapter 1: Introduction, Problem Statement, Objective, Scope, Report Organization.
    \item Chapter 2: Literature Review with at least three existing systems compared.
    \item Chapter 3: Methodology covering framework, requirements, design, data, POC, testing plan, and Gantt chart.
    \item References contain only works cited in the text.
\end{itemize}

\section{Recommended Class Patches}

If strict compliance with the 2019 guide is required, patch \texttt{umpthesis.cls} in this priority order:

\begin{enumerate}
    \item Remove \texttt{\string\aliaspagestyle\string{chapter\string}\string{empty\string}} so the first page of every chapter shows its page number.
    \item Restore chapter page numbers in the Table of Contents.
    \item Set body margins inside the class with \texttt{\string\geometry}.
    \item Change cover font to 20 pt and title page to single spacing.
    \item Add commands for spine, list of symbols/abbreviations, list of appendices, and list of publications.
    \item Replace \texttt{plainnat} with a strict APA 6th bibliography style.
\end{enumerate}
