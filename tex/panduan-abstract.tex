\begin{abstract}
This document combines the formatting specifications from the Universiti Malaysia Pahang Thesis Guide (2019) with the chapter-by-chapter content outline for the Projek Sarjana Muda (PSM) report. It also explains how to use the \texttt{umpthesis.cls} \LaTeX{} class to produce a report that follows the required format. The main chapters cover technical and formatting specifications, PSM report structure and content, step-by-step use of the \LaTeX{} class, and a submission checklist with known issues.
\end{abstract}
